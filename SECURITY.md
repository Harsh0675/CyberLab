# Security Policy

## Scope

CyberLab is designed for **authorized security assessment** of systems and networks that you own or have explicit permission to test.

## Responsible Use

Do not use CyberLab to:

- Access systems without authorization
- Steal credentials or sensitive information
- Deploy malware or persistence
- Bypass security controls or evade detection
- Disrupt services or damage systems

## Reporting a Vulnerability

If you find a security issue in CyberLab itself, please report it privately to the repository owner before public disclosure. Include a clear description, reproduction steps, affected file/component, and suggested remediation when possible.

## Safe Testing

Use CyberLab in an isolated lab, local VM, CTF environment, or another environment where you have explicit authorization.
